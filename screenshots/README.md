## How to Capture Mobile Screenshots in Chrome / Edge
1. Open the application in Google Chrome or Microsoft Edge.
2. Press **F12** (or `Ctrl + Shift + I`) to open Developer Tools.
3. Click the **Toggle Device Toolbar** icon (`Ctrl + Shift + M`).
4. Select **iPhone 14 Pro** or **Pixel 7** from the top dropdown.
5. Press `Ctrl + Shift + P`, type `Capture full size screenshot`, and save to this `screenshots/` directory.
